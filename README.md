# Salt Player for Linux

Salt Player（椒盐音乐）的 Linux 桌面适配版本，首个目标系统为 Ubuntu 24.04。

当前目标：构建 `v0.1.0-alpha`，提供本地音乐扫描、基础播放控制、播放队列、设置、Linux 桌面打包与发布流程。
