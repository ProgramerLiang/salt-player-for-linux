# Android 端能力调研与本仓库差距

调研口径：仅使用公开信息（`Moriafly/SaltPlayerSource` 的 release notes、issue 列表、公开截图与评测文章、SaltUI 公开 demo）。
**未使用任何原版私有代码或美术资源**；下表只描述行为与交互，实现全部自写。

| 原版能力（公开可见） | 本仓库现状 | 本轮处理 |
|:--|:--|:--|
| 播放页随封面主色的流动渐变背景 | 无（纯色底） | **本轮实现**（封面主色 + 缓慢流动 + 切歌淡入） |
| 逐字歌词：TTML（AMLL 风格 `span` 级时间）、YRC、增强 LRC | 仅逐行 LRC | **本轮实现**三种格式逐字解析 + 卡拉OK高亮，缺失逐字时回退逐行 |
| 双语歌词分行显示 | 部分（同时间戳合并 translation） | **本轮实现**（TTML agent / YRC 交替行 / LRC 同时间戳） |
| 均衡器预设（流行/摇滚/古典/人声/低音增强…）与自定义 | 内置预设，无自定义 | **本轮实现**（自定义预设保存/切换/持久化） |
| 页面切换、卡片悬浮、播放条展开动效 | 无（直接切换） | **本轮实现**（AnimatedContent + 悬浮阴影 + 播放条展开动画） |
| 播放队列拖拽排序 | 有排序按钮，无拖拽 | 本轮不实现（拖拽需自定义手势层，排期见 plan） |
| 桌面歌词（浮窗） | 无 | 未实现：需要独立 Wayland 层壳窗口，成本高，列为后续 |
| 小组件 / 通知栏控制 | 无 | 未实现：Linux 无对应载体；等价能力由 MPRIS 提供 |
| 标签编辑（写回文件） | 只读 | 未实现：写回需谨慎的原子写与备份策略 |
| 睡眠定时、播放统计、变速 | 已有 | 已完成 |
| 音效（响度归一/ReplayGain） | 已有标签读取 + 后端应用 | 已完成 |
| 歌词搜索/在线补词 | 无 | 未实现：需要在线服务，涉及版权与网络，超出本地库范围 |

## 用户本地库实测（用于本轮设计，不提交到仓库）

| 格式 | 数量 | 实测结构 |
|:--|:--|:--|
| `.lrc` | 451 | 网易云导出：文件开头是若干行 JSON 制作人信息（`{"t":0,"c":[...]}`），其后是标准 `[mm:ss.xxx]text`；本机样本**无**行内 `<mm:ss.xx>` 增强标记 |
| `.ttml` | 445 | AMLL 风格：`<p begin end ttm:agent="v1">` 内含 `<span begin end>字</span>`；`head` 里有 `<amll:meta key=...>`；本机样本只有 `agent="v1"`，无翻译行 |
| `.yrc` | 5 | 前 3 行为标题/艺人/作者，其后原文行与翻译行交替；**本机样本没有 `[start,duration]` 时间行** |

因此解析器必须：容忍 LRC 的 JSON 头、支持 TTML span 级时间与 `ttm:agent` 分组、YRC 同时支持「有时间行」与「仅文本+翻译」两种变体。
