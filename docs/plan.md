# 本轮排期与验收标准

顺序固定：调研 → 规格 → 实现 → 测试 → 截图证据。

## 1. 逐字歌词（规格 `dsl` 见下）

**行为规格**
- 输入优先级：同目录 `.ttml` → `.yrc` → `.lrc`（逐字优先），再回退内嵌标签。
- 数据模型：`LyricLine(timeMs, text, translation, words: List<LyricWord>)`；`LyricWord(timeMs, endMs, text)`。
- `words` 为空即"逐行歌词"，UI 回退到整行高亮；非空则做卡拉OK逐字填充。
- 双语：TTML 按 `ttm:agent`（v1 原文 / 其余为译文）分组；YRC 按"原文行 + 紧跟的译文行"配对；LRC 按同时间戳的第二行作为译文。
- 无时间行的 YRC（本机 5 个样本）：整文件按 `metadata 行`（前 3 行）+ 交替行解析，得到 `synced=false` 但保留 translation 配对。
- LRC 的 JSON 头（`{"t":..}`）必须忽略，不能污染歌词正文。
- 增强 LRC 行内 `<mm:ss.xx>` 标记解析为 words。

**验收**
- 单元测试：TTML（含多 span、缺 end、agent 分组）、YRC（有时间行/无时间行）、LRC（JSON 头、同时间戳译文、行内标记）。
- fixture 为本仓库自造同构小样本，**不提交用户歌词文件**。
- UI：播放页当前行逐字填充 + 上下行淡出。

## 2. 封面主色流动背景

**行为规格**
- 从封面缩略图采样主色（量化到 3bit/通道取众数，跳过近黑/近白），结果按 trackId 缓存。
- 背景 = 两个径向渐变叠加，色相在 ±20° 内缓慢往复（周期 18s），坐标随 26s 漂移。
- 切歌：新配色 600ms 交叉淡入，不硬切。
- 无封面：回退到主题强调色。

**验收**
- 单元测试：主色提取在纯色/带透明边/近黑图上返回可预期值；缓存命中不重复解码。
- 性能：每帧只做 2 个 brush 的 alpha/hue 插值，不解码图片、不做模糊；详见报告 E 节。

## 3. 均衡器预设

**行为规格**
- 内置预设保留；新增"自定义"：保存当前 10 段值为命名预设（写入设置），可切换、可删除。
- 切换预设立即下发后端；持久化到 `settings.json`。

**验收**
- 单元测试：预设增删改查、同名覆盖、上限数量、非法值裁剪。

## 4. 动效

- 页面切换 `AnimatedContent`（fade + 竖直滑动 12dp，220ms）。
- 卡片 hover 抬升（阴影 + 2dp 位移）。
- 播放条点击展开：高度与圆角动画。

**验收**：截图 + 目视；无自动化测试（Compose 动效不做快照测试）。
